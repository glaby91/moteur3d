# Tools

Python tools are grouped by their primary responsibility:

- `audits/`: scene and rendering diagnostics.
- `benchmarks/`: benchmark post-processing and experiments.
- `packaging/`: clean-release and asset-packaging scripts.
- `scene/build/`: scene and geometry builders.
- `scene/dispatch/`: scene-manifest resolution and validation.
- `scene/migrations/`: versioned scene changes and finishing passes.
- `blender/`, `photo2scene/`, `pripyat/`: focused workflows that retain their own structure.

Run repository tools from the repository root; CI workflows use the same paths.
