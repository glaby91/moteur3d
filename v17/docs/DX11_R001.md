# DX11 R001 — V17.025 (branche expérimentale)
Base : V17.024 master fad10eff46e5edff9616830a926ad4d5068b8a17. Aucun changement de scène, LumaTrace garde son filtrage et son shader de référence. R001 est actif par défaut dans cette branche, désactivation A/B par M3D_V17_DX11_R001=0.
- Frustum AABB par support de plans, double précision + marge conservatrice, échec ouvert si données invalides.
- Masques de visibilité réutilisés entre depth prepass et couleur pour les blocs et boîtes ; aucune réorganisation de triangles.
- Liste locale filtrée après sélection historique des 256 premiers : sources à énergie nulle, rayon non positif et volumes hors champ. Ordre des autres sources conservé. Aucun rejet d'une lumière qui touche un point visible ; la carte d'ombres globale reste inchangée.
