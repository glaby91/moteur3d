# LumaTrace adaptive budget 001 — V17.016
Default OFF. M3D_V17_LUMA_ADAPTIVE=1 enables only exact conservative budget zero/one.
Each group of 256 contiguous compact opaque primitive IDs has a CPU AABB containing all vertices. If no selected finite nonzero lamp sphere can intersect it (with conservative float padding), the compute writes zero RGB and the vertex shader forwards the existing no-radiance sentinel. Mixed groups use the original shader and ordered 64-light list. No geometry reorder, draw-call multiplication, probe changes, reflection changes, extra rays or GPU readback. Mask: 2 KiB; CPU bounds built lazily at first activation per scene, classification cached by light positions/radii/on-off state. Groups outside capacity fall back to baseline. Nonfinite light data is not rejected. Counts are conservative group classifications, not exact per-triangle occlusion counts.
Benchmark: LANCER_LUMATRACE_01_AB.bat, 1280x720 native present, VSync off, geometry prep on, hybrid probes on, 24 x 30s: day 14.75, night 23, transition 17 to 21 in six 5s steps (precomputed shadow maps), four repetitions with alternating OFF/ON order. Reports FPS, present-wall P50/P95 (not GPU timestamp), mean budget-zero triangle percentage and hardware JSON. No measured GPU speedup until hardware tests. WARP pixel parity test includes OFF/ON/OFF at day and night, plus all local lights removed.
