# Z Atmosphere 001 — V17.027 (experimental)
Activate M3D_V17_ZATMOSPHERE=1; M3D_V17_ZATMOSPHERE_DENSITY=.012 (range 0..0.04 inverse metres). OFF by default, no changes to scene, BVH4 or optical reflections. Shared physical approximation: integrate single scattering with four midpoint samples over up to 28 metres, reuse solar shadow map (one lookup per sample), at most four nearby authored lights, attenuation and premultiplied composition. No individual particles, no ray/triangle tests, no temporal randomness. Local lights unshadowed; abrupt changes of four selected lights possible. Density uniform, no room-specific atmospheric volumes, no true multiple scattering, no fine dust motes. Transparent surfaces use opaque depth, MSAA uses sample zero. Underwater disabled.
DX11/LumaTrace: GPU quarter-resolution linear target RGBA16F, four depth-weighted neighbours on upscale and fallback integration near silhouettes; main camera only; no CPU readback added. Peripheral multires bypassed while enabled (incomplete depth outside scissor). Vulkan: native full-resolution depth input attachment subpass, premultiplied blend before MSAA resolve; no CPU copy. Not yet quarter-res on Vulkan. Original rendering intended when OFF (verify pixel parity). Vulkan legacy UNORM color path blends in display space.
Five preflight numerical checks: zero density/length, homogeneous integral, distance monotonicity, density monotonicity. CI checks compiled math test and real V17.634 OFF/ON/OFF WARP day and night on DX11 and LumaTrace, PNGs. Vulkan SPIR-V and GPU smoke compiled; actual Vulkan ICD rendering and HD620 timing must be verified. No FPS claim.
