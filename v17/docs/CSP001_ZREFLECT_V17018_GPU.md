Exact primitive membership encoded only on LumaTrace transparent vertices; opaque radiance IDs and adaptive classification unchanged. Opt-in launch BAT; normal launch baseline. WARP real-scene first landing off/on/off regression, PNGs, and selected camera counters. GPU hardware FPS and image review remain required. Opaque mirror support, true refraction and shared elevator cubemap are not implemented by this stage; elevator retains original PBR.
