# V17.017 — indexed Z-Reflect diagnostic validation build

The native catalogue now builds a balanced spatial BVH once, queries it using conservative frustum bounds, and then projects only candidate patches. Offline diagnostic also computes an exhaustive oracle to prove identical projected fractions and selected IDs on every authored view. No global cap is applied. The 60,000-plane smoke test compares the index with exhaustive traversal at 64 directions; the sparse example requires 2 candidates with fewer than 128 node/plane tests, also checks overlap (64 visible, no truncation), unknown bounds, and empty trees. Synthetic timing is not a GPU performance claim.

The build packages the Windows engine, native diagnostic, route30 and benchmark programs, with the V17.629 author-policy overlay and report. The scene itself is downloaded separately. Only the existing water-reflection path is active in the renderer. Generic multi-plane GPU passes, runtime activation/target pool, reflection/refraction separation and actual cached lift probe remain unimplemented. A compiled package must not be labeled visually validated Z-Reflect until those stages are implemented and image parity is measured.
