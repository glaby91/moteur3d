# Z Material 001 — V17.030 candidate
Base: validated master 3a867911fce239439a81ce973fb239eb050c56af (V17.029).
One engine-level catalogue at materials/zmaterial8192.json, compact 64 families × 8 colors × 16 roughnesses; synthetic PBR presets, not measured optical data. No scene sidecar. Existing scene material declarations remain authoritative; optional `libraryMaterial: "inox_01_01"` fills missing properties only. Existing textureSet remains required; no catalogue textures are loaded. The modular runtime bridge filters declared materials by object instance references before PBR generation, rejects duplicate declarations/unknown materials and >256 active references, preserves declaration order. Legacy binary loaders are unchanged.
CPU computes material weights in the existing per-frame material constant preparation; no new buffer or per-frame catalogue lookup. A future optimization could cache these weights at scene load. Shader approximates directional ambient reflection, suppresses diffuse for opaque nonemissive metals, leaves water/glass/emission paths alone. DX11 adjusts roughness for metallic materials. LumaTrace shares DX11 final shading; its probe source calculation remains diffuse. No extra texture fetch, ray, camera, render pass. GPU timing is not measured. `M3D_V17_ZMATERIAL=0` disables shading correction (not catalogue selection). Default on in candidate only.
Previous internal synthetic benchmark: 31,850,496 configurations, 6912 opaque materials, mean metallic absolute luminance error 6.074 vs 1.928 points. This is not a real shader benchmark. Full WARP and hardware validation pending; no merge before validation. Existing CI scene and optical/atmosphere tests retained.
