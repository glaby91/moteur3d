# CSE WARP V17 — Linux Vulkan (experimental port)
Target Ubuntu 24.04 x86_64; Vulkan loader and device API >= 1.3.204. Same Vulkan raster/GLSL as Windows, not DirectX11 or LumaTrace. Linux uses GPU offscreen raster and QImage readback; native Linux WSI (X11/Wayland) not ported yet. Z Reflect currently belongs to LumaTrace DX11 and is not available in Vulkan. No scene embedded; download V17.631 from https://github.com/glaby91/moteur3d-scene/releases/latest or use application updater. 
Install runtime: sudo apt install libvulkan1 mesa-vulkan-drivers libgl1 libegl1 libxkbcommon-x11-0 libxcb-cursor0 libpulse0
Extract tar.gz, then ./lancer.sh [path/to/scene.json]. Vulkan is selected by default if compiled. CPU raster is not substituted automatically. Use Vulkan driver appropriate for GPU (Intel/AMD Mesa or NVIDIA). Software Vulkan is rejected by default; CSE_WARP_VK_ALLOW_SOFTWARE_TEST=1 only allows explicit CI lavapipe testing, not evidence of GPU performance. GitHub compiles with Qt 6.8.3, checks SPIR-V and Vulkan smoke; hardware, native WSI and Linux audio require independent validation. Windows backend defaults are preserved. The Linux package is built from the same engine revision as master.
