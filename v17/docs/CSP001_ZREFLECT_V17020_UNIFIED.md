# V17.020 — unified reflection passes
Water and authorized glass now share the exact projected-patch shortlist, two half-resolution GPU targets, mirror camera, clipping and sampler. Water retains its Fresnel, normal distortion, color and transmission. OFF still renders visible water for backwards-compatible glass A/B; ON selects both. The active counter counts each selected pass once, including water. No occlusion query yet. The v2 cache includes water; v1 falls back to building the catalogue. Scene V17.631 is to be published using the v2 compiler. The old mesh helper remains for other code/tests but no longer drives the DX11 LumaTrace renderer. WARP validates selection and renders water; physical GPU quality/performance still requires local A/B. Opaque mirrors and refraction are not implemented in this change.
