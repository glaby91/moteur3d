# AVX2 moteur 3D — build 261103-0010

Noyaux séparés sous `src/simd/avx2/` : génération caméra par paquets de huit, tests de triangles par paquets homogènes, test des deux enfants BVH et accumulation diffuse par groupes de lumières ponctuelles, plus AA contours. Le mode automatique utilise le dispatch CPU/OS; le chemin x64 standard reste sélectionnable.

Les matériaux, textures, normales, réflexions spéculaires, primitives non triangulaires, parcours BVH par paquets de rayons et DOF contiennent encore des calculs scalaires. Les résultats doivent être comparés sur les mêmes scènes/réglages avant de conclure sur le gain global.
