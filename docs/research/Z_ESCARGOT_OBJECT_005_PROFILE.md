# Object005 profiling campaign
Branch based on validated Object005 24e176c. No visual algorithm changes.
Native window, no image staging; opt-in CSE_WARP_ESCARGOT_PROFILE=1 uses a completion event plus 5 timestamp markers around Luma compute, optical pass, primary render and GPU copy. Completion wait is benchmark-only, not production frame rate; invalid/disjoint timestamps explicitly marked. WARP is software, not HD620.
Planner stages: receiver selection, sparse discovery, source ranking, triangle footprint cull, transparent sorting, vertex emission, tested objects/triangles, actual rays and omitted candidates. GPU optical upload bytes, CPU map/allocation/upload, layer and scissor area, cache hits and draw counts.
Four modes: no optics, Z Reflect, projected sky-only (same receiver map, same planner and same cache policy; no copy of geometry), full Object005. 3 views, 2 motion modes, 3 resolution/MSAA configurations, 2 warmups and 4 recorded frames each; 432 records including warmups. Exterior named preset selected and logged, explicitly marked synthetic if unavailable. Hardware launcher uses 640x360 and 1280x720. No performance or visual quality claims until results are inspected.
