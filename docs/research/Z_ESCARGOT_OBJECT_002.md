# Escargot Object 002 — one-layer research

Preserve G F16, BVH4, scene, materials and main branch. New diagnostic first, not a production renderer. Discover one named artwork from reflected BVH hits, build one coplanar UV chart from geometry, compute reflected ray/plane intersection globally (no UV interpolation, no tile-specific projection). Exact triangle containment. Nine diffuse proxy lighting samples in source coordinates, reused across camera poses. Visibility separate, limited adaptive local refinement with shared sample cache, 256/1024/4096 BVH query budget. Unknown distinct from occluded. Dense oracle on same chart and camera compares coverage; export three poses 0/7.5/15 cm with candidate, oracle and mask PNG. Synthetic case includes thin occluders, exposes missed occlusions and budget exhaustion. No automatic promotion, no performance claims: CPU diagnostic only; no integration into GPU shader yet. Source name selection must match actual scene; noncoplanar/multi-chart surfaces, transparent crossings, ripple/specular and real lighting require further validation. Discovery is once per session, not per pixel or per frame. All geometry and texture remain unchanged.

## Second numerical pass
The original traversal consumed the entire small budget before reaching the far side of the footprint (e.g. 24,164 unknown of 24,791 projected points at budget 256). Allocate a budget-dependent coarse seed across the entire image before local refinement; only refine measured visible/occluded transitions. Outside-domain and unknown samples are excluded from interpolation; measured points are preserved. This removes budget-driven coverage holes in the synthetic trial but can miss thin occluders; report false-visible and false-hidden pixels separately. Mask interpolation is approximate, not certified continuous at all subdivision boundaries. Future work: conservative projected occluder bounds and shared-edge mask reconstruction, full GPU integration. No source UV interpolation.
