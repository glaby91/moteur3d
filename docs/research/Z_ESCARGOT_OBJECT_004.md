# Escargot Object 004 — raster direct GPU

Experimental branch from Object003. Reuses validated original BVH4 hierarchy and source UVs, per-frame raster receiver position and authored eligibility; no sparse UV interpolation or CPU primary visibility. GPU traces reflected rays with original triangle IDs, up to 16 straight transmission crossings, front-to-back alpha and actual source texture; no per-frame optical image readback on native swapchain. Scene buffers cached by geometry revision and eligibility. Existing F16 and Z Reflect fallback retained. Startup flag CSE_WARP_ESCARGOT_OBJECT_GPU=1; engine-only launcher sets flag and existing Escargot toggle. GPU shader is compiled separately (PS 5.0), original default PS remains intact. Uses native float division, not the bit-exact CPU division emulation; exact CPU/GPU equivalence not established. Source lighting is approximate solar/shadow/probe shading, not a complete cached lighting matrix. No Snell refraction or Narrow16 compact planar fast path in this initial GPU branch; direct per-fragment BVH is a quality-first integration baseline and may be slower. Smoke requires Object004 without fallback, changed image vs A/F16, camera motion, A restored, real native HWND and no full-frame readback. WARP timings are software-only; package must pass smoke before upload. Main unchanged.

### Z-prepass regression correction
Restore Object004 pixel shader after the depth-only draw, not the legacy raster shader. A/B smoke compares water-only receiver permissions against an all-disabled catalogue and requires a measurable optical signal. Both images are exported even if the gate fails. This validates a water contribution, not a perfect reference image.
