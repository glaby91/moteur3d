# CSE WARP V17.494 — DXGI native DirectX 11 + interface regroupée

## Portée
Développement dans la branche existante `integration/v17-493-complete-vulkan-hd620-261115` (aucune nouvelle branche).
Version exécutable forcée : **17.494**, vérifiée en CI Windows. Scène V17.493 et matériaux inchangés.

## Présentation
- Backend D3D11 Raster : case **Affichage GPU direct (DirectX 11 / Vulkan)** cochée par défaut.
- Le même HWND natif utilisé pour Vulkan héberge une swapchain **DXGI 1.2 flip sequential à 2 buffers**, créée sur le thread du moteur DirectX.
- Rendu PBR et MSAA inchangés dans les textures existantes ; copie **GPU→GPU** dans le backbuffer DXGI, puis `Present(0,0)`. **Pas de texture staging, de Map, de copie CPU ou de QImage par image**.
- Le ciel animé est rendu sur le GPU en mode natif : pas de composition QPainter asynchrone qui nécessiterait la lecture CPU.
- Recréation swapchain lors du changement de taille / HWND et libération lors du passage à Vulkan, CPU ou rendu D3D11 hors écran.
- En cas d'échec DXGI, récupération via le mode QImage original et désactivation du mode natif pour la session.

## Interface
- Les panneaux « Explorateur de scène » et « Réglages de rendu » sont groupés en onglets sur le même côté, pour agrandir la zone 3D sur 1366×768.
- Barre supérieure : caméras 1 à 6, sélection moteur rapide synchronisée et bouton Actualiser.
- Position de caméra et FPS dans la barre d'état, toujours visibles dans le mode natif **tant que cette barre n'est pas masquée par le plein écran F11**.
- Les outils de diagnostic, d'export PNG et d'analyse de la scène restent accessibles dans l'ancien mode QImage en décochant l'option.

## Validation et limitations
- CI compile sur Windows + tests de non-régression ; cela ne constitue **pas un benchmark matériel HD 620**.
- Pas de chiffres de FPS anticipés. Comparer en 1366×768 sur le Dell, même caméra et qualité, mode GPU direct coché / décoché, au moins 90 frames.
- Pas de nouvelle texture, dégradation PBR, changement des réglages MSAA ou modification de la scène.
- Le HUD Qt au-dessus du QWindow natif ne peut pas être peint avec QPainter. Les métriques principales sont déportées en barre d'état ; le HUD incrusté en plein écran natif nécessitera un rendu GPU dédié.
